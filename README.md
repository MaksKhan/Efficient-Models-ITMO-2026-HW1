# HW1: модель стоимости SmallCNN

- `hw1.ipynb` — основное решение с формулами, кодом эксперимента и графиками.
- `hw1_handwritten.pdf` — вывод формул от руки.
- `models.py`, `equations.py` — сеть и функции FLOPs, memory, latency, energy. Остальные `.py` — измерение, подбор констант и построение графиков.
- `results/` — текущие измерения, параметры модели, имена CUDA kernels и графики.

## Как повторить

Запустить `hw1.ipynb` сверху вниз в Colab или Kaggle с GPU; все `.py` файлы должны лежать рядом с ноутбуком. Нужны PyTorch, NumPy, SciPy, Matplotlib и доступ к NVML для измерения мощности. Результаты записываются в `results/`. Для нового GPU сначала убрать или переименовать существующую папку `results/`, чтобы не смешивать измерения.

## Результат

MAPE на отложенных точках: latency 23.75%, memory 34.07%, energy 20.00%. Максимальный измеренный пик памяти — 5.75 GiB против 4.75 GiB по формуле.

Запуск на Kaggle: Tesla T4 (16 GB видеопамяти; системную ОЗУ не фиксировал), PyTorch 2.10.0+cu128, CUDA 12.8, cuDNN 9.10.2. В Colab на этой неделе закончилась квота GPU.
